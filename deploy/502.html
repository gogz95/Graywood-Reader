502
Backend Service Offline / Unreachable

Bad Gateway

The web proxy received an invalid response or was unable to connect to the Graywood Reader backend server. The service may be starting up, rebooting, or temporarily offline for maintenance.

Common Administrator Fixes

  • Ensure the Node.js / Docker service is running on port 3000.
  • If deploying via Docker Compose, run:
docker compose ps && docker compose logs --tail=50 -f
  • If running via PM2 or Systemd:
systemctl status manhuasync.service # or: pm2 status
  • Verify Nginx upstream proxy address in nginx.conf (proxy_pass http://127.0.0.1:3000;).
