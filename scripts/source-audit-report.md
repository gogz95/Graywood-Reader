## Architecture comparison: this web clone vs. Kotatsu (KSP)
Kotatsu registers sources via the `@MangaSourceParser` Kotlin annotation + a KSP
annotation processor (`kotatsu-parsers-ksp`) that generates the source registry at
compile time. Each parser is compiled Kotlin and owns its domain via `ConfigKey.Domain`
or the base-class constructor — no runtime regex is needed, so domains are always
authoritative. This Node port cannot compile Kotlin, so it regex-scans `.kt` files and
must replicate every declaration form (ConfigKey.Domain, base-class constructor, bare
literal) to avoid registering dead `<id>.com` URLs. `extractParserDomain` is kept in
sync with server.ts so the audit reflects the live registry.
